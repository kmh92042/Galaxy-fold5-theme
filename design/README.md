# Midnight Awakening · 디자인 리소스

오리지널 성인 여성 캐릭터가 네온 야경을 배경으로 보랏빛 마법 무기를 든 K팝 판타지 콘셉트입니다. 블랙 베이스, 퍼플 림라이트와 차가운 블루를 사용하고 상단을 어둡게 비워 시계 가독성을 확보합니다.

- 원화: `../public/art/nocturne.png`, AI 생성 PNG, 1086 × 1448. 기존 작품의 캐릭터나 로고를 사용하지 않은 독립 디자인입니다.
- 배경: `exports/wallpapers/`의 외부 904 × 2316, 내부 1812 × 2176, 외부 잠금 904 × 2316. 같은 원화의 크롭 변형이며 원화 확대가 포함됩니다. 잠금 배경은 상단을 추가로 어둡게 처리합니다.
- 아이콘: `exports/icons/`의 192 × 192 PNG 8종. 투명한 바깥 여백과 둥근 사각형 베이스를 가진 오리지널 대체 심볼입니다. 공식 앱 로고가 아닙니다.
- 벡터 정의: `../src/theme.ts`의 `iconSvg`. 화면 규격은 같은 파일의 `surfaces`.
- `preview.png`는 웹 UI 스크린샷이며 기기 설치 결과가 아닙니다.

기본 출력값: 어둡기 16%, 가로 위치 58%, 아이콘 포인트 #A78BFA. 이미지 교체와 다운로드로 수정할 수 있습니다. 업로드 파일은 메모리에만 유지됩니다.

앱 아이콘용 심볼은 테두리와 컬러 광원으로 통일했으며, 실제 알림 배지·마스킹·크기는 삼성 런처/Theme Park의 적용 방식에 따릅니다. 웹 미리보기의 시계·날씨·위젯은 PNG에 없습니다.
