# Wings of Dawn · 로스트아크 니나브 팬 테마

니나브의 금빛 머리, 엘프 귀, 흰 날개와 빛의 활을 재해석한 **AI 생성 비공식 팬아트**입니다. 공식 원화·게임 스크린샷·로고를 추출하거나 사용한 결과물이 아니며, 게임 모델과 디테일이 다를 수 있습니다. 로스트아크 및 니나브 관련 권리는 원 권리자에게 있습니다. Smilegate 공식 상품이나 삼성 공식 테마가 아닙니다.

## 방향

- 주조색: Midnight navy `#090E16`, Champagne gold `#D8B77A`, Celestial blue `#88CFE8`.
- 배경: 별이 보이는 천공 성전, 금빛 아크 구조물, 니나브 중심의 판타지 팬아트.
- 아이콘: 금속성 이중 테두리, 성물 문양, 푸른 에나멜, 금빛 앱 심볼의 8종 세트. 공식 앱 로고가 아닌 런처용 대체 심볼.
- 가독성: 상단을 비워 시계 공간을 확보하고 잠금화면에 추가 암부를 적용. 모든 니나브 배경의 하단에는 앱 이름 가독성을 위한 네이비 그라데이션을 적용하며 미리보기와 PNG에 동일하게 반영합니다.

사용자가 제공한 삼성 참고 URL은 현재 클라우드 환경의 프록시 접근 정책에서 403으로 차단되어 실제 내용을 확인하지 못했습니다. 이 디자인은 해당 페이지를 복제한 것이 아니라, 사용자가 선택한 ‘특정 캐릭터 중심’ 방향에 따라 니나브를 중심으로 새로 제작한 콘셉트입니다.

## 파일

- `../../public/art/lostark-oath.png`: 캐릭터 팬아트 원본. 원화보다 큰 출력에서는 확대가 포함됩니다.
- `exports/wallpapers/cover-904x2316.png`: 외부 홈 배경.
- `exports/wallpapers/inner-1812x2176.png`: 내부 홈 배경.
- `exports/wallpapers/lock-904x2316.png`: 외부 잠금 전용 배경. 시계와 위젯은 포함하지 않습니다.
- `exports/icons/`: 전화·메시지·카카오톡·유튜브·갤러리·카메라·설정·음악, 각 192 × 192 PNG.
- `preview.png`: 실제 웹 스튜디오 스크린샷. 실물 폴드5 적용 화면이 아닙니다.
- `../../public/downloads/LOSTARK-Nineveh-Fold5.zip`: 위 배경 3종·아이콘 8종·적용 가이드가 들어 있는 기본 팩.

기본 편집값은 어둡기 12%, 가로 크롭 62%, 포인트 컬러 #D8B77A입니다. 한 원화를 외부/내부 화면에 맞게 크롭하고 잠금 배경은 상단을 추가로 어둡게 만듭니다. 원화는 1086 × 1448 PNG입니다. 출력 픽셀 크기가 원화의 네이티브 해상도를 의미하지 않습니다.

## 적용

ZIP을 휴대폰에 옮겨 ‘내 파일’에서 압축을 풉니다. 배경은 설정 → 배경화면 및 스타일에서 지정하고, 아이콘은 Good Lock → Theme Park → 아이콘의 앱별 이미지 변경 메뉴로 지정합니다. 내부 화면의 배경은 기기를 펼친 상태에서 설정합니다. 내부 잠금 배경에는 inner PNG를 사용합니다. 메뉴와 지원 범위는 기기·One UI·Theme Park 버전에 따라 다릅니다.

이 팩은 **수동 적용용 PNG**입니다. 설치형 `.apk`/`.mtpk`, 통화 UI, 시스템 알림창, 카카오톡 내부 테마는 제공하지 않습니다. 실물 폴드5 적용은 미검증이며, PNG 크기와 웹 내보내기 동작을 브라우저에서 검증합니다.
